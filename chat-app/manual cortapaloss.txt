=====================================================================
 MANUAL CORTAPALOSS - CHAT PERSISTENTE
 (directo al grano, sin vueltas)
=====================================================================

QUE ES
------
Un chat web con link para compartir. Creas una sala, mandas el link,
y todos los que lo abran chatean ahi. TODO queda guardado en MySQL:
cierras el navegador, vuelves a abrir el link y ahi esta el historial.

Stack: CodeIgniter 4 + Bootstrap 4 + jQuery (AJAX) + MySQL.
Toda consulta a la base pasa por procedimientos almacenados.
Todo es gratis y open source.

=====================================================================
 1. INSTALAR (una sola vez, el script es idempotente:
    lo puedes correr las veces que quieras)
=====================================================================

LINUX / MAC:
    cd chat-app
    bash setup.sh

WINDOWS:
    Doble clic en  chat-app\setup.bat
    (o en PowerShell:  powershell -ExecutionPolicy Bypass -File setup.ps1)
    Si no tienes PHP/MySQL, el script los instala con winget.
    Si usas XAMPP, el script lo detecta solo (C:\xampp).

El script:
  - Instala PHP, Composer y MySQL si faltan (con reintentos automaticos).
  - Crea la base de datos "chat_persistente", el usuario "chat_user"
    con password aleatorio, tablas y procedimientos almacenados.
  - Genera la configuracion FUERA del repo:
        Linux/Mac:  ~/chat-app.env      (enlazado como chat-app/.env)
        Windows:    %USERPROFILE%\chat-app.env  (copiado a chat-app\.env)
    Ese archivo NUNCA se sube a git.

=====================================================================
 2. ARRANCAR
=====================================================================

    cd chat-app
    php spark serve

Abrir en el navegador:  http://localhost:8080

=====================================================================
 3. USAR
=====================================================================

1) En la portada pones un nombre de sala y le das "Crear sala".
2) Te da un link tipo  http://localhost:8080/c/a1b2c3d4e5f6a7b8
3) Copias el link y se lo mandas a quien quieras.
4) Cada uno pone su nombre y a chatear. Se actualiza solo cada 2 seg.
5) El historial NUNCA se pierde: abre el link de nuevo y ahi esta todo.

=====================================================================
 4. SI ALGO FALLA
=====================================================================

"No conecta a la base de datos"
    -> Corre de nuevo el setup (setup.sh / setup.bat). Es idempotente.
    -> Revisa que MySQL este corriendo:
         Linux:   sudo service mysql start
         Windows: services.msc -> MySQL -> Iniciar (o panel de XAMPP)

"El puerto 8080 esta ocupado"
    -> php spark serve --port 8081
       (y cambia app.baseURL en ~/chat-app.env al mismo puerto)

"Quiero borrar todo y empezar de cero"
    -> mysql -u root -e "DROP DATABASE chat_persistente;"
    -> corre el setup de nuevo.

"Perdi el password de la base"
    -> Esta en ~/chat-app.env (Linux/Mac)
       o %USERPROFILE%\chat-app.env (Windows).

=====================================================================
 5. MAPA DEL CODIGO (por si quieres tocar algo)
=====================================================================

chat-app/
  app/Config/Routes.php        <- rutas (limpias y comentadas)
  app/Controllers/Home.php     <- portada + crear sala
  app/Controllers/Chat.php     <- sala + AJAX (enviar/traer mensajes)
  app/Models/RoomModel.php     <- salas (solo llama CALL sp_...)
  app/Models/MessageModel.php  <- mensajes (solo llama CALL sp_...)
  app/Views/home.php           <- portada (Bootstrap 4 + jQuery)
  app/Views/chat.php           <- chat (Bootstrap 4 + jQuery + polling)
  database/schema.sql          <- tablas + procedimientos almacenados
  setup.sh / setup.ps1 / setup.bat  <- instaladores idempotentes

Procedimientos almacenados (los unicos que tocan las tablas):
  sp_room_create(slug, name)          crea sala
  sp_room_get(slug)                   busca sala
  sp_message_send(slug, sender, txt)  guarda mensaje
  sp_messages_fetch(slug, after_id)   trae mensajes (0 = todo)
