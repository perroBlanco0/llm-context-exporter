# Changelog

All notable changes to this extension are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-25

### Added

- `Copy for LLM Prompt` explorer context-menu command that copies the selected
  files and folders to the clipboard as a single Markdown document.
- `Export for LLM Prompt (Markdown file)` command that writes the same output to a `.md` file.
- `Copy Workspace for LLM Prompt` command palette entry for the whole workspace.
- ASCII file tree plus fenced file contents with language detection.
- `.gitignore` support (including nested `.gitignore` files), extra ignore globs,
  binary-extension and binary-content detection, and size/file limits.
